# Submission checklist

- [ ] Test the application in Chrome/Edge.
- [ ] Confirm the Metropolia REST API loads restaurants.
- [ ] Confirm daily menu works.
- [ ] Confirm weekly menu works.
- [ ] Test search and filters.
- [ ] Test registration and login.
- [ ] Test favourites.
- [ ] Test profile editing.
- [ ] Test profile picture upload.
- [ ] Allow browser location permission and test nearest restaurant.
- [ ] Test the map.
- [ ] Validate HTML and CSS.
- [ ] Push the project to GitHub with meaningful commits.
- [ ] Upload the project to users.metropolia.fi or another public server.
- [ ] Open the public URL in an incognito window and test again.
